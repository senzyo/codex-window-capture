- When using Computer Use, use `sky.get_window_state({window,include_screenshot:false,include_text:true})` by default to inspect window controls. When you need an image, activate the uniquely identified target window, run `& "$env:LOCALAPPDATA\codex-window-capture\scripts\capture-window.ps1" -ApplicationPath <absolute-path-to-application> -WindowTitle <full-current-window-title>` in the interactive user's context outside the command sandbox, and inspect the returned PNG. For sandboxed `exec_command` sessions that allow escalation, set `sandbox_permissions:"require_escalated"`; for unsandboxed sessions, omit that parameter. If capture fails, check the execution context, foreground window, executable path, and full title before retrying; do not automatically fall back to Sky's native screenshot capture.
